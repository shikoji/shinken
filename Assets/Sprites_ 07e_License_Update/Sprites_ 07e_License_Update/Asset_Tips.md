# Solaria Asset Tips

##### 

##### Quick Guide to Recolouring Solaria Assets



This can be done in basically any art program and is incredibly easy to do. Individual programs obviously work in different ways so your workflow may be a little different. There are other, faster methods for recolouring, but this one provides the most control in my experience.



1. Find the Solaria palette included with your download and copy it into your chosen program. 
2. Find the asset you want to recolour and paste it in.
3. Choose a colour ramp from the palette.
4. Work from lightest to darkest, or vice versa using the paint bucket tool to change the colours one by one. 

   1. You may find it useful to mask off parts of the image using the marquee or magic wand tools, or to turn contiguous fill on/off.
   2. Avoid saving over the original assets if possible.
5. Make sure to save assets as PNG files.



This process will also work for animations, as every frame of a particular animation will be on the same sprite sheet.



The palette I use is not perfect, with many similar colours, so feel free to experiment with other palettes and colours, and tweak things to your liking.

##### 

##### Removing Shadows



1. Select the transparent colour from the palette (usually indicated by a checkerboard pattern), or use the eyedropper tool to pick it from anywhere on the canvas without a colour.
2. Use the paint bucket tool to replace the shadow colour with transparency (some assets may use multiple shades for shadows so you may need to repeat this step).
3. Make sure to save assets as PNG files.



##### Icons



If using RPG Maker, consider editing the IconSet file down to only the icons needed for your project, as large icon sets may cause issues depending on your hardware.
